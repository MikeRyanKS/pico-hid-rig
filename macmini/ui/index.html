Screen calibration

Maps the Pico's absolute range (0–32767) to macOS points. Drive the cursor to each extreme, read its coordinate on the target with ⌘⇧4, type the two numbers in, then Compute & Save. Everything else (zones, clicks) uses this.

Zones clamps all clicks

A zone is the rectangle (in macOS points) the automation is allowed to touch — e.g. exactly Display 1 or Display 2. The active zone is saved into the profile; the Pico can never move or click outside it. Read a display's position & size from System Settings → Displays.

Mouse pattern

Randomized, human-like clicking within the active zone. Leave Targets empty to click anywhere in the zone, or add sub-rectangles to concentrate clicks.

Typing

When enabled, some actions type a random phrase instead of clicking. You can also toggle the keyboard live from the status bar during a session.

Session

How the session runs. Autorun = start automatically on power-up, no Mac needed. Loop = after finishing the click count, reshuffle and keep going.

Profile

Build the profile from all tabs, then push it to the device. In stealth mode the Pico saves it to its own flash and runs it on every plug.
